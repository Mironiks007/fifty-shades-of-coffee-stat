# Совместная работа

1. Перед изменениями обновить свою копию репозитория.
2. Создать ветку с понятным названием, например `analysis/moisture`.
3. Согласовать, кто меняет какой раздел блокнота. Одновременное редактирование одного `.ipynb` часто создаёт конфликты; для параллельной работы можно временно использовать отдельные блокноты в `notebooks/`.
4. Выполнить блокнот целиком после перезапуска ядра. Проверить пути к данным, подписи осей и выводы.
5. Сделать коммит и открыть pull request в `main`.

Исходный CSV не редактировать вручную. Фильтры и преобразования должны быть видны в коде. Не добавлять токены, пароли, виртуальные окружения и временные файлы. Не подписывать p-значение как вероятность истинности нулевой гипотезы.

Перед сдачей заполнить таблицу `cat_mark_table` по требованиям преподавателя и проверить, что все ссылки открываются.
