# Совместная работа

1. Перед изменениями обновляем свою копию репозитория
2. Работаем в своей ветке
3. Договариваемся, кто редактирует какие файлы и разделы
4. После изменений проверяем результат и сохраняем его в коммите

## Спринт 2: инфохимики и дизайнеры

разделяем работу по веткам:

- `s2/infochemistry`
- `s2/design`
- `main` - общая согласованная версия проекта

Обе ветки создаём от актуальной `main`. Перед началом работы согласовываем задачи и файлы, которые будем менять

Готовые изменения добавляем в `main` через pull request. Перед объединением проверяем, что расчёты, оформление и пояснения согласуются между собой

После объединения обновляем свои рабочие ветки из `main`, чтобы учитывать изменения другой команды

Одновременное редактирование одного `.ipynb` может привести к конфликтам. Изменения общих блокнотов согласовываем заранее. При конфликте проверяем спорные ячейки вместе, затем выполняем итоговый блокнот целиком

## Данные и файлы

Исходный `coffee_ratings.csv` сохраняем без изменений. Фильтрацию, нормализацию и остальные преобразования выполняем в коде блокнота

Для второго спринта используем отдельный блокнот `stat-lab1-s2.ipynb`, сохраняя результаты первого спринта в `stat-lab1-s1.ipynb`

## Перед сдачей

- Проверяем имя блокнота и соответствие ссылок текущему спринту
- Выполняем все ячейки после перезапуска ядра
- Проверяем расчёты, подписи осей, отображение формул, таблиц и графиков
- Сверяем выводы с рассчитанными значениями
- Актуализируем состав участников и коэффициенты вклада в `cat_mark_table`
- Проверяем ссылки в блокноте и README
- Объединяем согласованные изменения в `main`
