# Fifty Shades of Coffee statistic

Exploring the darker side of coffee with statistics. Infochemistry Lab 01: distributions, dependencies, and questionable caffeine consumption.

Статистический анализ влажности и органолептических характеристик кофе.

## Открыть работу

[Основной блокнот](notebooks/Lab01.ipynb) · [Открыть в Google Colab](https://colab.research.google.com/github/Mironiks007/fifty-shades-of-coffee/blob/main/notebooks/Lab01.ipynb)

В блокноте выполнены подготовка данных, EDA трёх величин, проверка нормальности, анализ связей, оценка средних с доверительными интервалами и моделирование поведения оценок при увеличении выборки. Итоговую работу нужно сверить с полным текстом задания преподавателя; таблицу участников и коэффициенты заполняет команда.

## Данные

`data/coffee_ratings.csv` — предоставленный участником проекта CSV, сохранённый без изменений: 1339 строк, 43 столбца. Первоисточник описания набора: [jldbc/coffee-quality-database](https://github.com/jldbc/coffee-quality-database), сбор отзывов Coffee Quality Institute в январе 2018 года. У исходного проекта описаны 1340 отзывов; предоставленная здесь версия отличается числом строк. Побайтовое совпадение с файлами первоисточника не утверждается.

Одна строка — запись об оценённом образце/партии кофе, а не отдельное зерно или человек.

| Величина | Столбец | Интерпретация |
| --- | --- | --- |
| Влажность | `moisture` | Значение в исходной числовой шкале файла; 0.11 соответствует записи о влажности, а не баллу дегустации |
| Кислотность | `acidity` | Дегустационный балл воспринимаемой кислотности; не pH |
| Полнота напитка | `body` | Дегустационный балл; не физическая плотность |

Кофеин, pH и концентрации кислот в таблице не измерены. Это набор с физическим показателем влажности и сенсорными оценками, а не три лабораторных химических анализа.

Основная выборка: **1058 записей Arabica** с заполненными положительными значениями трёх выбранных показателей. Робусту анализируем отдельно только в исходном описании. Нулевая влажность не объявляется документированным кодом пропуска: эти записи считаем подозрительными и исключаем по явному правилу. Последствия исключения проверяются в анализе чувствительности. Ненулевые выбросы сохранены.

## Локальный запуск

Нужен Python 3.10 или новее. Из корня репозитория:

```bash
python -m venv .venv
```

Активировать окружение: Windows PowerShell — `.venv\Scripts\Activate.ps1`; Linux/macOS — `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Открыть `notebooks/Lab01.ipynb` и выполнить все ячейки сверху вниз. В Colab блокнот сам загружает CSV из этого публичного репозитория, если локального файла нет.

## Ограничения

Набор содержит оценки отобранных образцов, а не случайную выборку всего кофе в мире. Наблюдения могут быть связаны общей фермой, происхождением и процедурой оценивания. p-значения и интервалы рассчитаны при модельном предположении независимости строк; их нельзя автоматически переносить на всю кофейную продукцию. Корреляция не означает причинность. Моделирование повторных выборок иллюстрирует работу оценок на эмпирическом распределении, а не доказывает репрезентативность данных.
