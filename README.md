# Fifty Shades of Coffee - stat

Exploring the darker side of coffee with statistics

Лабораторная работа 1 по инфохимии: исследуем влажность зёрен, кислотность и полноту напитка

## Открыть работу

[Основной блокнот](stat-lab1-s1.ipynb) · [Открыть в Google Colab](https://colab.research.google.com/github/Mironiks007/fifty-shades-of-coffee-stat/blob/main/stat-lab1-s1.ipynb)

В работе:

- Обосновываем выбор трёх случайных величин
- Подготавливаем данные и проводим EDA
- Выполняем нормализацию и стандартизацию
- Оцениваем средние и строим доверительные интервалы
- Проверяем связь показателей и статистические гипотезы
- Сравниваем нормальную и логистическую модели с учётом допущения об округлении
- Исследуем состоятельность оценок среднего и дисперсии
- Сравниваем выборки с возвращением и без возвращения

Таблица участников и коэффициенты вклада заполнены в конце блокнота

## Данные

Используем `coffee_ratings.csv` из [TidyTuesday](https://github.com/rfordatascience/tidytuesday/tree/main/data/2020/2020-07-07): 1339 записей и 43 столбца

Данные собраны с сайта Coffee Quality Institute в январе 2018 года и опубликованы в [Coffee Quality Database](https://github.com/jldbc/coffee-quality-database)

Одна строка соответствует записи об оценённом образце кофе

| Величина | Столбец | Единицы |
| --- | --- | --- |
| Влажность зёрен | `moisture` | Доля |
| Кислотность | `acidity` | Дегустационный балл |
| Полнота напитка | `body` | Дегустационный балл |

Единицы влажности проверили по [скрипту очистки исходного проекта](https://github.com/jldbc/coffee-quality-database/blob/master/clean_coffee_data.R): значения в процентах делятся на 100

Для основного анализа оставляем **1058 записей Arabica** с заполненными положительными значениями трёх показателей

Значение нулевой влажности в документации не объясняется, поэтому отдельно проверяем, как исключение таких строк влияет на результаты. Ненулевые крайние значения сохраняем

## Локальный запуск

Нужен Python 3.10 или новее

Из корня репозитория создаём виртуальное окружение:

```bash
python -m venv .venv
```

Активируем его в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

В Linux или macOS:

```bash
source .venv/bin/activate
```

Устанавливаем зависимости и запускаем JupyterLab:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Открываем `stat-lab1-s1.ipynb` и выполняем все ячейки сверху вниз

В Google Colab блокнот загружает CSV из публичного репозитория, если локального файла нет

## Ограничения анализа

Выводы относим к подготовленному набору Arabica. Представительность этих данных для всего кофе в мире не установлена

При расчёте интервалов и проверке гипотез используем указанные в блокноте предположения о независимости наблюдений. Дополнительно проверяем устойчивость связи кислотности и полноты с учётом стран и ферм

Повторный отбор из таблицы позволяет исследовать поведение оценок для эмпирического распределения. Причинное влияние показателей друг на друга по этим данным не устанавливаем
