# Передача: КТвД-часть лабораторной 1

Дизайнерская часть (оформление + доп. задание) собрана в ветке `s2/design`.
Этот файл — что уже сделано и что осталось доделать команде.

## ✅ Что сделано

- **Доп. датасет (доп. задание КТвД)** — `stat-lab1-s2.ipynb`
  TripAdvisor: рейтинг ресторанов и число отзывов (108 178 заведений, 31 город).
  Доказательство случайности, EDA, нормализация, логнормальная модель,
  проверка независимости (ρ Спирмена ≈ −0,05 → практически независимы; главный
  вывод: значимость при огромном n — артефакт размера выборки), перестановочный
  тест, χ², состоятельность оценок, выборки с возвращением/без.
- **Единый тёмный стиль «Тёмная обжарка»** — `lab_style.py`
  Нейтральный тёмный фон, засечки, векторные графики, 2 акцента
  (кофе — янтарный, HoReCa — жёлтый).
- **Кофейный блокнот в тёмном виде** — `s1_dark.ipynb`
  Перекрашены только графики; расчёты, выводы и структура инфохимиков НЕ менялись.
- **Интерактивный генератор выборок (marimo)** — `marimo_generator.py`
  Ползунки (величина, объём выборки, способ отбора, seed) → выборка против
  генеральной совокупности вживую. Экспорт в самостоятельный HTML (работает в
  браузере без терминала): `showcase/generator.html`.
- **Статический сайт-хаб с навигацией** — папка `showcase/`
  `index.html` (хаб) → тёмные `s1.html`, `s2.html`, `generator.html`.
  Пилюли-навигация между частями + боковая навигация по разделам лабы.

## 🚀 Деплой сайта (коротко, Тихон)

Сайт статический, бэкенд не нужен. С этой ветки:
```
git fetch && git checkout s2/design
# папку showcase/ отдать любым статическим хостингом:
#  - nginx: root на папку showcase/
#  - или Netlify/Vercel: перетащить папку
#  - или GitHub Pages: скопировать в docs/ и включить Pages
```
Открывается `index.html`. Зрителю (преподу) нужен только интернет — генератор и
формулы подтягивают библиотеки с CDN. Полные детали — `showcase/README.md`.
